# Dynamic Link Manager

A Blender extension for replacing linked assets and characters with ease.

## Features

- **Scan Scene**: Automatically detect all linked assets in your Blender scene
- **Asset Replacement**: Replace individual linked assets with new files
- **Batch Operations**: Manage multiple linked assets efficiently
- **User-Friendly Interface**: Clean, organized UI in the 3D View sidebar

## Installation

1. Download the extension files
2. In Blender, go to Edit > Preferences > Add-ons
3. Click "Install..." and select the `blender_manifest.toml` file
4. Enable the "Dynamic Link Manager" addon

## Usage

### Accessing the Tool
- Open the 3D View
- Press `N` to open the sidebar
- Look for the "Dynamic Link Manager" tab

### Basic Workflow
1. **Scan Scene**: Click "Scan Linked Assets" to find all linked assets
2. **Select Asset**: Click on a linked object in your scene
3. **Replace Asset**: Use the "Replace Asset" button to choose a new file
4. **Verify**: Check that the replacement was successful

### Supported Asset Types
- Linked Objects
- Linked Meshes
- Linked Materials (coming soon)
- Linked Textures (coming soon)

## Requirements

- Blender 4.5.0 or later
- Windows 10/11
